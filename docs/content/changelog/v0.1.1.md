# v0.1.1 — Release on a tag.

Nothing changes for the workflows that call the action: the inputs, the
outputs and what it publishes are those of v0.1.0. This release changes how
the action itself is released and maintained.

## Releases

- A pushed version tag is released by the repository's `cd` workflow: it
  checks that GitHub verifies the tag's signature, that the tagged commit is
  on `main` and that the release note exists, runs the tests, and publishes an
  immutable release with the note as its body.
- Each release is checked with `gh release verify` before `cd` turns green.

## Maintenance

- `ci` and `cd` report their results to Slack.
- Stale issues and pull requests are closed after 37 days without activity,
  unless marked `status: pending`; completed workflow runs are deleted
  monthly.
